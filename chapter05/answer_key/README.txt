第5章习题参考代码

在answer_key目录使用JDK 17执行：
  javac -encoding UTF-8 --release 17 -d out Chapter05Answers.java
  java -cp out Chapter05Answers
显式检查失败会抛出AssertionError，无需-ea。out为本机生成目录。

5-8主任务为脱敏装饰器与服务端岗位列集合，LegacyPrinterAdapter为选做。5-9保护代理先检查price:export，外层审计记录SUCCESS/DENIED/FAILED；可信Actor由认证授权层提供。5-10增加岗位只改列策略配置。
