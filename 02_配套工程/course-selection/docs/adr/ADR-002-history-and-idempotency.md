# ADR 002 历史行与独立请求快照

状态：采用。

问题：原教材片段复用同一选课行，依当前ACTIVE关系判断重复请求；发生选课→退课→旧请求重试时，当前状态无法代表那次操作是否成功。

备选：①直接重新激活旧行，会混淆历史与新意图；②每次插历史行并用包含状态的普通唯一键，重复退课历史可能冲突；③保留历史行，生成列只约束ACTIVE，独立请求表保存成功响应。

决定：采用③。退课旧行WITHDRAWN，再选新行；学生+幂等键唯一并校验目标。请求快照与选课、计数同事务。旧键返回同一快照，即便其关联已经退课，也不创建新选课；新意图必须换键。

收益：保留审计，可处理响应丢失、并发重复和旧请求重放。

代价：增加请求存储和快照维护，客户端须理解“操作结果”与“当前课表”不同；本例无过期清理政策，正式系统需另订保留期限。

证据：旧键退后重放、同键双并发、新键重复有效关系、同键不同目标409、回滚请求表全部撤销。关联R02/R03、C03/C04/C06。
