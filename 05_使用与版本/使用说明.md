# 第二版配套资源使用与版本说明

本资源包包含第十章完整参考工程、实践指导、设计决策与重构、图件及验收资料。完整解压后，从00_总览.html进入各部分。

## 目录

| 位置 | 内容 |
|---|---|
| 02_配套工程/course-selection | 前后端源码、测试、迁移与固定数据、锁文件、运行脚本、API、ADR、重构、需求追踪及图件 |
| 03_实践指导 | 可编辑的实验指导与记录、教学组织与评价参考 |
| 04_测试与验收 | 验收报告、89份原始记录压缩包、逐项路径索引及校验 |
| 05_使用与版本 | 本说明 |

## 复现与使用

1. 进入02_配套工程/course-selection，按README准备PowerShell 7、JDK 17、Maven 3.9、MySQL 8.0和Node 22。
2. 配置专用开发库与测试库，初始化空库，先执行scripts/verify.ps1，再启动前后端。测试库独立使用，测试会重置其中的数据。
3. 结合实践指导完成六项功能、权限、并发、幂等与回滚核对，保留自己的操作和数据库结果。参考工程已有能力与个人改动分别说明。
4. 查看历史证据时，打开04_测试与验收/验收报告.html；原始记录ZIP中的本机绝对路径仅用于回溯，当前命令以README为准。
5. 比较下载ZIP的SHA-256与同一Release中的SHA256SUMS.txt。解压后的文件清单也位于资源包根目录。
